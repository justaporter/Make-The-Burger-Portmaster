## Notes

Make burgers with assorted ingredients, memorize orders and be quick before time runs out. Make your customers happy by eating delicious hamburgers, but remember, nobody likes to get wrong orders.

thanks to DoubleFury for creating such a fun game.

This is not AI slop hardcoded to one CFW or device, it works on all devices using Portmasters Standards

To obtain the files to this port, open Steam Console and type or paste the command 
download_depot 1358610 1358612 7027764266055537486
The files location will be shown after complete. Copy the data.win file from here to the maketheburger/gamedata folder.
